# Governance

Ultimate Quickshell is an open-source community project.

The repository owner currently acts as maintainer and release manager. Contributors can propose changes through issues and pull requests.

Technical decisions should favor:
1. correctness and security;
2. maintainability;
3. performance and resource efficiency;
4. native Quickshell/Wayland integration;
5. accessible configuration and documentation.

As the contributor community grows, maintainership and review responsibilities can be expanded through documented changes to this file.
